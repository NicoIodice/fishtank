### 🟡 MINOR-001: Weak Assertion in AC-8 Test (System Events)

**Location:** [FileLoggingTests.cs](src/Fishtank.Api.IntegrationTests/FileLoggingTests.cs#L497-L517) — `SystemEvents_WrittenTo_LogFile`  
**Issue:** The test only verifies the log file is non-empty, not that System Events specifically are logged.

**Current Assertion:**
```csharp
content.Should().NotBeEmpty(
    "Log file must contain entries. Every System Event generated by the infrastructure " +
    "layer must be written to both stdout and the rolling log file (AC-8, NFR-18).");
```

**Risk:** False positive — any log entry satisfies this assertion, not just System Events.

**Recommendation:** Assert for a specific System Event signature or known log message template:
```csharp
content.Should().MatchRegex(@"(@l|Level).*?(Information|Warning|Error)",
    "Log entries must include severity levels per NFR-18");
```

### 🟡 MINOR-002: Loose Regex in AC-9 Test (Resync Outcomes)

content.Should().MatchRegex(

### 🟡 MINOR-004: Timing Waits Using Task.Delay

**Location:** Multiple tests in [FileLoggingTests.cs](src/Fishtank.Api.IntegrationTests/FileLoggingTests.cs)  
**Issue:** Tests use `await Task.Delay(TimeSpan.FromSeconds(2))` to wait for Serilog async flush.

**Examples:**
- Line ~180: `await Task.Delay(TimeSpan.FromSeconds(2));`
- Line ~200: `await Task.Delay(TimeSpan.FromSeconds(2));`
- (repeated in multiple tests)

**Risk:** Potential flakiness on slow CI runners; wastes time on fast machines.

**Recommendation:** Use a polling/retry pattern with timeout:
```csharp
private async Task WaitForLogFileAsync(string logFile, TimeSpan timeout)
{
    var deadline = DateTime.UtcNow + timeout;
    while (DateTime.UtcNow < deadline)
    {
        if (File.Exists(logFile) && new FileInfo(logFile).Length > 0)
            return;
        await Task.Delay(100);
    }
}
```

**Verdict:** Acceptable for now — 2-second delay is reasonable. Optimize if flakiness observed.
